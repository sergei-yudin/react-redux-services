# Redux: управление услугами и фильтрация

Домашняя работа Нетологии к занятию «Redux». Объединяет задания «Редактирование» и «Фильтрация»: добавление, редактирование и удаление услуг, валидация формы, поиск без учёта регистра и статистика результатов.

```bash
npm install
npm run dev
```

Состояние списка, формы и фильтра хранится в Redux. Производный отфильтрованный список вычисляется мемоизированным селектором `reselect`.
